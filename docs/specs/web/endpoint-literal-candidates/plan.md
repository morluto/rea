# Plan

Keep the declaration facet in the domain analyzer, like the existing route
facts: dedup, count and record omissions there, and let the worker fit the
selected literals into the per-script result budget it already owns. One leaf
module owns the ceiling constants so the setting definitions and the analyzer
both read them without an import cycle. The ceiling travels as an admission
(`maximumCount`, `source`) through the existing analysis-setting path, so launch
seeds, runtime updates and worker requests use one contract. Byte trimming
skips candidates in source order and stops nothing, and the omission record
carries both causes so the result message can point at the control that actually
bound the facet. Guides keep product behavior; the limit inventory owns the
setting's registration.
