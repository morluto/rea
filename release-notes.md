###   BREAKING CHANGES

* **comparison:** preserve same-entry correspondence across renames ([#8263](https://github.com/morluto/rea/issues/8263))

* **mcp:** MCP tool arguments now default to 1,024 combined array elements and object members per call. Select a larger positive finite REA_MCP_MAX_INPUT_ELEMENTS allowance and restart for larger inline inputs, or use retained/file selectors where supported. Inputs are never truncated.

* **cli:** preserve native value input diagnostics ([#7889](https://github.com/morluto/rea/issues/7889))
* **javascript:** report ambiguous artifact paths ([#7864](https://github.com/morluto/rea/issues/7864))
* **environment:** Environment state and coverage can report method-replay for non-GET safe reads; exhaustive reason consumers must handle it.
* **web:** retain invalid browser selection ([#7903](https://github.com/morluto/rea/issues/7903))
* **ghidra:** Ghidra now returns not-in-listing for in-memory addresses without listed instructions or defined data. Consumers matching the former undecodable value must handle the new status.
* **input:** classify unresolvable source paths ([#7847](https://github.com/morluto/rea/issues/7847))
* **session:** classify unavailable snapshot prerequisites ([#7837](https://github.com/morluto/rea/issues/7837))
* **process:** reject unsupported one-column terminals ([#7848](https://github.com/morluto/rea/issues/7848))
* **process:** sensitive interaction data is empty with sensitive and input_bytes fields instead of a byte-count placeholder. Sensitive raw_data is also redacted. Read input_bytes and recapture both comparison sides when migrating older private-input Evidence.
* **setup:** managed MCP registrations use the selected absolute runtime and REA entry script, including package-runner cache paths. Keep that installation available or restore it before setup; unknown registrations require confirmed manual repair. Setup no longer returns prewarm or emits its progress events.
* **hopper:** macOS Hopper launches refuse double quotes, backslashes and line breaks in final helper paths or arguments before application handoff. Select literal-safe launcher/runtime/database paths and loader arguments, or a compatible provider. Original executable names can remain unchanged when their prepared image path is literal-safe.
* **javascript:** consolidate renderer and route ownership
* **ownership:** Replace Cutter --json=true or --json=false with --json-output=true or --json-output=false. Bare --json still controls CLI result formatting.
* **ownership:** rea compare-bundles has been removed. Use rea compare instead. The MCP compare_bundles tool is unchanged.
* **jeb:** JEB engine refusals now report execution_failure rather than unsupported_target. Consumers should inspect the retained upstream diagnostics for the engine's reason and recovery facts.
* **artifacts:** ASAR file occurrences may now contain unpacked: false. Consumers that validate only true must accept an optional boolean; absent historical fields remain unknown.
* **environment:** The write-plan reason can now be unknown-clock; strict clients must accept the new output value.
* **mcp:** non-loopback deployments require MCP_ALLOWED_HOSTS or rea mcp --http --allowed-hosts; bundle names must be unchanged HTTP hostnames within the 63-octet DNS label bound.
* **mcp:** binary_session {} no longer returns analysis_provider_candidates[].availability.diagnostics, target_support.diagnostics or capabilities, or tool_availability group surface, effects and annotations. Pass {"detail": "complete"} to get them.
